# Changelog

All notable changes to Klipboard will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html)
for Klipboard releases. The initial version follows the KDE Klipper 6.8.2
source version.

## [6.8.3] - 2026-11-17

### Added
- Settings to configure standard and terminal paste shortcuts between Ctrl+V and Ctrl+Shift+V.

### Fixed
- Explicitly set `Qt::RichText` format on configuration dialog hint labels.

## [6.8.2] - 2026-11-12

### Added
- Initial standalone Klipboard release based on KDE Klipper 6.8.2.
- Debian, Fedora RPM, and Arch Linux package builds.
